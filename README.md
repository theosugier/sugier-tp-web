# Zero Day

Projet de TP initiation web (HTML / CSS) - B1 Ynov Aix

C'est un jeu d'aventure ou tu joues un pentester qui teste le reseau d'une entreprise la nuit et qui se rend compte que quelqu'un d'autre est deja connecte. A chaque page tu as 2 choix et il y a 3 fins possibles (scene08, scene09 et scene10).

Lien du repo : https://github.com/theosugier/sugier-tp-web

Installation et lancement

Il n'y a rien a installer, c'est juste du HTML et du CSS. Il faut juste un navigateur (Chrome, Firefox, Edge...).

1. Recuperer le projet :
git clone https://github.com/theosugier/sugier-tp-web.git
(ou telecharger le zip depuis GitHub avec le bouton Code puis Download ZIP)

2. Ouvrir le dossier sugier-tp-web et double cliquer sur index.html

La police vient de Google Fonts donc il faut internet pour l'avoir, sinon le jeu marche quand meme avec une autre police.

Le fichier arbre-navigation.pdf montre toutes les pages et ou mene chaque bouton.

Les pages des scenes sont dans le dossier pages, les images et videos de fond dans assets/backgrounds et les icones des boutons dans assets/icons.
